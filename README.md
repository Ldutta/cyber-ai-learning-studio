# Learning Studio · Cybersecurity × AI

A local-first learning tracker with editable curriculum tracks, per-topic progress, notes, resources, projects, planner, dark mode and browser data backups.

## Run locally

Requires no build tools or dependencies. In the project directory run `python3 -m http.server 8000`, then open http://localhost:8000 in Chrome. Opening `index.html` directly also works.

## Data

User progress and notes stay in this browser profile in localStorage. They do not sync across devices. Use Settings to export or restore a JSON backup.

## GitHub Pages

This repository is private. GitHub Free personal accounts require a public repository for Pages; eligible paid plans can publish from private repositories, but the site is generally public on the internet unless enterprise private-site access applies. Do not enable Pages until site visibility is chosen.

The curriculum and resource links were transcribed from the provided ChatGPT roadmap; linked resources are kept in `curriculum.js`.
